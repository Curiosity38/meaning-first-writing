# 写作故障与表达修订

从入口按需读取；这些是诊断方法，不是禁词表，也不能据此判断作者身份或保证通过 AI 检测。先看上下文中的信息与功能，再决定是否修改；引语、专名、标题及讨论某种表达的文字不按模式直接替换。

## 1 防御性免责声明

**故障**：每个判断之后附上一串“但不代表……”“不能完全证明……”“也不排除……”，让句子形式上安全、实际没有主张。

**修复**：先陈述已有证据支持的判断，把对象、条件和范围写进句子。只有影响理解或报告要求的限定才需要保留，不强求每个结论都附带一句局限。不同层级要分清：已观察事实、合理推断、假设、未知。真正影响医疗、法律、安全、科研解释的限制必须保留。

> 不佳：“这可能说明一定的相关性，但不能排除其他因素，也不代表必然存在影响。”
>
> 较好：“在当前样本中，A 与 B 同向变化；由于未控制 C，结果不足以支持 A 导致 B。”

## 2 习惯性否定与假冲突

**故障**：不经分析就写“不是 A，而是 B”，制造“纠正众人”的姿态，甚至将本来并存的两件事写成对立面。

**修复**：先判断 A/B 关系到底是对立、条件、因果、并列还是递进；使用准确连接词。当否定纠正真实误解，或两部分分别提供独立信息时，保留必要的对比。

> 不佳：“科研不是为了发表文章，而是为了培养能力。”
>
> 较好：“科研既可能产出论文，也能训练提出问题和检验证据的能力。评价本科生科研经历时，应把参与程度、实际产出与训练收益分开讨论。”

## 3 平凡真命题与信息空转

**故障**：正确但无帮助——“学习有价值”“结果有好有坏”“不同人情况不同”；通过反复排比制造篇幅。

**修复**：把每句泛泛判断压成一个具体问题：**谁、在什么条件下、发生了什么、因为什么、和什么相比、影响多少？** 材料没有回答时，不假造答案；改为清楚指出决定问题的变量。

> 不佳：“本科生既要上好课，也要注重实践，促进全面成长。”
>
> 较好：“判断一项竞赛是否值得投入，先看它要求学生做的是复述已有方案，还是自己提出问题、设计实验并处理失败结果；这决定了它能提供何种训练。”

## 4 用姿态代替证据

**故障**：通过“值得注意的是”“深刻揭示”“关键转变”“重构范式”“本质上”等词，把本应证明的观点直接宣告为结论。

**修复**：拿掉强调词，审查剩余主谓宾和论证是否成立。结论可以鲜明，但必须能指向具体证据、比较对象或推理步骤。证据薄弱时缩小命题，不用形容词充当证据。

## 5 字面服从，丢失情境

**故障**：用户说“稍微包装，不要太水”，模型就改成堆叠“协同、闭环、沉淀、赋能”；被纠正后又改成过于幼稚的日记。

**修复**：根据**写作者身份、读者身份、场景中正常的表达尺度**定语言。把隐含需求落实为可读文本，而非字面风格标签。生活表达要有真实动作与感受，专业表达要有明确对象与结果。

## 6 套话、术语堆叠与机械排比

**故障**：名词接名词、万能词接万能词，几段共用同一骨架；“一个”泛滥，“不是……而是……”“首先……其次……最后……”反复出现。

**修复**：抽象表达优先改为“主体＋动作＋对象＋结果”；保留专业领域真正必需的术语，并在第一次出现时说明其操作性含义。再检查句子是否只是先否定一个笼统说法，接着提出另一个笼统说法。可以直接写清人在什么情境下做什么、依据是什么；没有必要用“只有……才……”把普通建议写成绝对规律。重复若没有强调或解释作用，就删去。**不要机械禁用特定词汇**：必要的排比、转折、限定与技术术语仍可使用。

## 7 虚假中立与问题替换

**故障**：明明要评价具体行为，却用“双方都有合理诉求”结束；明明是可核实的证据冲突，却把它包装成观点差异；或把一个尖锐问题改写成温和、容易答的价值观问题。

**修复**：先回答原问题。事实分歧查证事实，价值分歧交代标准，信息不足说出**缺哪项信息会改变判断**。多视角是为了更准确地判断，而非默认对半分配可信度。争议话题应公平呈现相关观点，但不制造虚假等价。

## 8 六类需要清理的表达

先完成意义与证据检查，再检查段落是否忙于自证、反驳想象中的批评或描述项目内部流程。下表是定位线索；是否修改取决于这句话在当前体裁中起什么作用。

| 类型 | 常见表现 | 修改方法 |
| --- | --- | --- |
| 审计式 | 反复强调冻结、锁定、PASS、哈希和“已经严格核验” | 直接陈述必要的设计事实，将复现细节放入 Methods 或补充材料；内部管理状态从论文中删除 |
| 防御式 | 每个结果后接“不意味着”“不能说明”“我们并未声称” | 写清研究对象、条件和发现；确实影响解释的限制保留一次，放在对应结论附近 |
| 自我批评式 | “遗憾的是”“仅仅”“我们承认”，表格逐行自评好坏 | 中性报告实际结果或设计选择；阴性、矛盾结果保留，影响读表的计数与注释保留 |
| 评判与说教式 | 宣布“真正的问题”、评论别人怎样理解、连续反问 | 写出这段话要表达的事实或关系，并核对它是否成立 |
| 开发人员式 | 用文件名、目录、脚本状态和内部代号讲研究结果 | 换成数据集、方法、变量或实验条件的名称；公开编号、软件版本、必要随机种子及数据访问入口保留 |
| 承诺式 | 用“接收后公开”“后续会补充”代替当前数据或代码状态 | 说明目前存在且可用的资源与访问条件；缺少入口时明确向作者提出，不编造链接或已完成状态 |

### 每句话怎样处理

先问：删掉它，会不会改变读者对数值、实验设计、结论或可复现性的理解？

- 会影响解释、报告要求或某项数值是否报告：保留事实，在它起作用的位置写清楚。
- 只用于复现：移到 Methods 或补充材料；转移后确认信息仍完整。
- 只有安抚、重复自证或内部管理作用：删掉。
- 属于阴性、矛盾结果或预设评价标准：作为结果或设计事实保留。预设项目缺少结果时，指出缺项，不能删掉标准来消除问题。
- 需要作者提供证据、资源或授权：记录具体缺口；语言修改不能替代实际补充。

改写以正面说明范围为主。例如，已知样本来自三所学校，可写“本研究调查了三所学校的学生”，无需在每次提及时再补“我们并未声称代表所有学生”。但如果抽样范围会影响某项外推结论，就应在该处交代。

一段写清一件事。不要把所有例外塞进结果句，也不把必要条件统一搬到文末，以致读者先看到一个范围过大的结论。确有作用的否定句可以保留。

### 按体裁使用

这六类判断主要用于科研正文、补充材料、图注、表注和数据/代码声明。README 的安装命令、交接报告的状态、审稿回复对实际质疑的回应，以及基金申请中有依据的未来计划，都可能是正文所需内容。先确认用途，再处理语气。

## 9 模板表达与机械节奏：按功能合并检查

先处理段落形状，再处理词语。同一套路跨句、跨段反复出现也需要检查；一个词、一个短句、一个三项列表或一种标点本身不构成修改理由。段落别扭时围绕原有意思重新组织，不把逐词替换当作完整改写。

| 检查点 | 修改依据与边界 |
| --- | --- |
| 起跑式铺垫与伪深度 | 删除只预告下文的“让我们深入看看”、假装揭示本质的格言；已有定义和判断直接说。真实比喻、作者有意的停顿与语境中的坦率表达可保留 |
| 戏剧性碎片与收尾 | “这才是真正的价值”、解释刚讲完的例子等若只是复述就删；短句若新增事实、后果或表达作者真实强调则留。检查每节是否机械附同一种结语 |
| 三项排比与开头复读 | 逐项核对独立信息，合并同义项，保留不同功能、时间和动作；不按项目数量判错，不为变化补第四项，也不强改有意排比 |
| 破折号与句长 | 反复靠破折号掩盖分句关系时改为准确的标点或重写；保留有作用的插入、转折及作者惯用节奏。英文范围符号、负号和固定术语不当修辞标点删，不设置统一配额 |
| 限定与被动 | 压缩同层的不确定性叠加，保留作用范围不同的限定。已知施事者且主动更清楚时可改主动；未知或不重要时保留被动，不能编造主语 |
| 高频词与意义拔高 | 检查“赋能、至关重要、robust、pivotal”等是否空泛、重复或用错，技术用法可保留；删只表赞美的“彰显了”及无依据的 -ing 尾句，保留真实原因、目的和后果 |
| 宣传、关联与权威 | 用已有特征代替无内容赞美；材料说明具体关系时直接写，未知则不补身份。保留归因及其确定程度，不把“专家认为”变成自己的事实，也不编引用补权威；无依据论据按修改授权处理 |
| 冗长系词与生造标签 | 在含义一致时用“是、有、做”或直接动词，解开无定义的复合词；保留数量、比较、能力与完成状态。“超过”不改成“等于”，“可提供”不改成“已提供” |
| 装饰排版 | 粗体标签、表情、箭头和分隔线无阅读作用时可精简；流程箭头、必要强调与定位信息保留。文件标题和锚点遵守保护规则，不机械取消列表或把散文拆成提纲 |
| 聊天与草稿残留 | 独立文章删无内容的客服式夸奖、邀约和“刚补了本段”等过程说明；保留其中的事实。邮件礼貌、变更日志的版本差异、可追溯来源和影响行动的说明按用途保留 |
| 资料时效与猜测 | 重复知识边界声明可压缩，保留界定时效的日期和实质资料缺口。不以“保持低调”等解释填补未知，也不把原有猜测改成事实 |
| 中文句式与标点 | 长串“的”按原修饰范围拆解；“进行＋动词”冗长时改直接动词，保留时态和状态；四字格、被字句按文体处理。正文标点遵从中文习惯和用户样本，代码与原文引语不受替换 |
| 英文句法与标点 | 核对复合修饰语的连字符是否符合词典、位置及目标格式，不全删或全留；被动、名词化、引号样式和标题大小写服从文体。正式词和技术术语不因命中词表改成口语 |
