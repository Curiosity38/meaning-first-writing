# 中英双语写作与翻译

## 翻译和改写是两种授权

逐句忠实翻译时保留结构和主张，不顺便重写论证。要求英文润色或双语成稿时可调整句法与信息顺序，但两种语言的证据范围必须相同。仅在用户要求双语时提供两种版本。

专业术语以作者给定的词表、领域惯例及全文一致性为准；缩写首次定义后保持统一。多义术语若改变科学含义且无法从上下文判断，应指出歧义，不能凭流畅程度选择。

## 必须对齐的意义

| 原文信息 | 修订检查 | 常见错误 |
| --- | --- | --- |
| may / suggest / consistent with | 保留可能、提示或一致性层级 | 翻成“证实”“证明” |
| not / only / except / unless | 核对否定和条件的作用对象 | 将“仅在 A 下”变成普遍成立 |
| observed / simulated / predicted | 保留数据产生方式 | 将模拟结果写成实验验证 |
| correlation / mechanism | 保留关联与机制的区别 | 用因果动词替代关联 |
| n、单位、均值与误差 | 数值含义、精度、误差类型一致 | 丢掉单位、把 SD 改成 SEM |
| relative change / percentage points | 区分相对百分比和百分点 | 从 80% 到 84% 写成提升 4% |
| first-person experience | 只译作者实际陈述的经历 | 增补情绪、细节和成绩 |

例如：“The measurements are consistent with mechanism A.” 可译为“这些测量结果与机制 A 相符”，不能译成“测量证实了机制 A”。若 A 与其他机制都能解释结果，语言上的确定性不能消除这种不可区分性。

英文改稿优先使用明确的主语、动作、对象和条件；保留领域中有精确含义的被动语态与名词化。不要将中文长句逐词展开为英文长句，也不要为了简短删除条件从句。

## 最后一遍对照

按段核对观点、引文位置、数字、符号、否定、时间、比较对象和语气强弱；再读两种语言各自是否通顺。若源文存在矛盾，指出源文问题，不通过翻译悄悄替作者决定。
