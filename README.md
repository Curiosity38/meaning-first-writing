# Meaning-First Writing

**让 AI 写的文章真正回答问题。**

Meaning-First Writing 是一个支持中英文写作的 Skill，适用于论文、报告、评论和申请材料。起草时，它帮助明确问题、组织材料和展开论证；修改时，它检查证据能否支持结论、段落是否重复，以及表达是否符合语境。

## AI 写了 3000 字，到底回答了什么？

比如问 ChatGPT：“本科生做科研和参加竞赛，哪个更值得投入？”

它可能这样回答：

> 科研和竞赛各有优势，应该根据个人兴趣、未来规划和时间安排综合考虑，两者都有助于提升综合能力。

这段话读起来很顺，也没有明显错误。可把“科研和竞赛”换成“考研和就业”，它几乎还能照用，因为回答只给出了笼统的建议，没有分析科研与竞赛在具体任务、时间投入和训练收获上的差别。

这种只讲原则、不展开分析的写法，在长文中也很常见。论文的 Introduction 花了几百字介绍研究意义，具体的科学问题仍然含糊；Results 反复说“显著提升”，却没有交代比较对象和指标变化；评论罗列了各种立场，却没有说明哪种判断更有依据。文章看起来完整，读者仍然得不到需要的解释。

Meaning-First Writing 就从这些问题入手：**文章要回答什么？每一段提供了什么新信息？结论由哪些事实和推理支持？**

## 先把比较标准讲清楚

回到科研和竞赛的例子。如果要比较两者对科研能力的训练价值，首先需要明确判断标准：

> 先看学生在项目中能承担哪些工作：有没有机会提出问题、设计方法、分析失败原因，并根据结果调整方案？能让学生深入参与这些环节的项目，通常比只安排重复操作的项目提供更深入的科研训练。具体选择科研还是竞赛，还要比较实际职责、指导反馈和时间投入。

有了这些标准，读者就能比较手头的具体项目。同样的方法也适用于报告、申请材料和评论：“收获很大”要说明做过什么、学到了什么；“方案更好”要说明比较对象和依据；“研究很重要”要交代它解决了什么问题。

## Skill 如何处理文章？

开始写作前，先确认用户要回答的问题、读者的背景，以及现有材料能支持哪些结论。起草新文章时，据此组织内容；修改已有稿件时，先弄清作者的观点、依据和语气，以免改写后偏离原意。

确定文章要说什么之后，再检查论证是否成立。重复表达同一观点的段落可以合并。遇到缺少依据的结论，先检查现有材料；若仍找不到支持它的证据，就标出缺口或调整结论。同时还要留意文章是否偏离原题，例如用“真正的问题是……”把具体问题换成宽泛的讨论。

内容和论证理清后，再处理机械排比、生硬转折、抽象套话和反复免责。删改时要看这些表达在句子中是否有实际作用。例如，“可能”若反映真实的不确定性，就应保留；反复出现的“不能排除”如果没有说明究竟什么因素会影响结论，就可以删去。

具体规则见 [常见写作问题与修复方法](references/writing-failures.md) 和 [交付前检查](references/review-gates.md)。

## Scientific Writing：让科学问题、数据和结论接得上

我平时经常用 AI 辅助论文写作，因此单独做了一个 Scientific Writing 模块，针对 Introduction、Results、Discussion 和 Methods 中常见的论证问题进行检查。

**Introduction** 需要说明已有研究解决了什么、还留下什么困难，以及本工作打算如何研究。以球、壳和棒的跨结构光学预测为例，它们的几何参数定义不同，直接用几何参数建立统一模型时，输入变量的含义难以保持一致。由此就可以引出一个研究思路：尝试使用不同结构共享的电磁响应变量。

**Results** 要交代比较对象、条件和实际变化。例如，给定一组固定测试集上的**演示数据**，可以这样报告误差变化：

> 在该测试集上，MAE 由 0.13 降至 0.09，绝对下降 0.04，相对下降约 30.8%。

若要进一步解释误差下降的原因，还需要相关的对照实验或其他证据。使用“统计显著”等表述时，也应提供相应的检验依据。

**Discussion** 应回到文章最初提出的问题，说明结果支持了哪些解释、增加了什么认识，并据此提出值得进一步检验的问题。

**Methods** 则要交代研究对象、关键参数、数据划分、重复次数和统计方法，使其他研究者能够理解并尽可能复现研究过程。

模块还涵盖摘要、图注、基金申请书、研究计划及中英文论文修订。无论修改哪一部分，原始数字、引文、实验条件、阴性结果和必要的科学限定都需要准确保留。详细规则见 [Scientific Writing](references/scientific-writing.md) 和 [中英双语写作](references/bilingual-writing.md)。

## 安装与使用

按照所用工具的说明，将完整项目目录放入 Skills 路径，并保留 `SKILL.md` 及其引用的 `references/`、`examples/` 等文件和目录。如果使用支持文件上传的对话环境，也可以直接提供 `SKILL.md` 和需要的参考文件。

**修改现有文章：**

> 使用 Meaning-First Writing 修改下面的文章。尽量保留作者原有的事实、主要观点和必要限定，检查文章是否回应了原问题、是否有重复内容，以及论据是否支持结论。如发现证据不足，请指出具体缺口并调整相应表述。直接给出修改后的全文。

**修改科研论文：**

> 使用 Meaning-First Writing 的 Scientific Writing 规则修改下面的 Results。保留原始数字和比较条件，梳理结果之间的关系，区分实际观察与机制推断，不添加未提供的数据。
