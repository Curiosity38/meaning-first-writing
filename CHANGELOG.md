# Changelog

All notable changes to this project are documented here. Versions follow Semantic Versioning.

## [1.1.0] - 2026-10-20

- Shorten the entrypoint and move detailed failure diagnosis into an on-demand reference.
- Add editing-depth, source-conflict, quotation, compression, and deliverable rules.
- Add bilingual terminology and evidence-strength consistency guidance.
- Extend scientific guidance with source tracing, statistical units, evaluation levels, and manuscript consistency.
- Clarify that inherited PDF page references were not independently verified.
- Add Codex UI metadata, input hashes, release packaging, failure-case tests, and cross-platform CI.
- Expand semantic regression prompts and document how to record real evaluations.
- Replace repository placeholders with the user-selected Curiosity38 destination.

## [1.0.0] - 2026-10-20

- Package the original meaning-first-writing instructions as a standards-compatible, root-level Agent Skill.
- Preserve reference guides for pragmatics, scientific writing, source critique, editing examples, and quality review.
- Add bilingual GitHub README files, dependencies documentation, manual and Skills CLI installation instructions.
- Add dependency-free structural validation, GitHub Actions, and manual semantic regression prompts.
